## Getting Started


### To run the project

1. Clone the repo
   ```sh
   git clone https://github.com/mors-incarnatum/CBINOV3-SEALs.git
   ```
2. Go to Project Directory
    ```sh
   cd CBINOV3-SEALs/seals
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Run the project
   ```sh
   npm run dev
   ```
5. Open http://localhost:3000 in your browser.
